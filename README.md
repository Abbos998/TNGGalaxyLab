[![CI](https://github.com/Abbos998/TNGGalaxyLab/actions/workflows/ci.yml/badge.svg)](https://github.com/Abbos998/TNGGalaxyLab/actions/workflows/ci.yml)

> **This repository reproduces every figure, table and statistic
> presented in the paper.**
>
> - **Zenodo DOI:** [10.5281/zenodo.21363952](https://doi.org/10.5281/zenodo.21363952)
> - **MNRAS manuscript:** submitted (Nuritdinov, Mirtadjieva & Omonov 2026)
> - **Sample:** 915 disc galaxies from IllustrisTNG50-1 at z = 0

A reproducible Python pipeline for the Fourier decomposition of stellar
surface density in simulated disc galaxies, tailored for large
cosmological simulations such as IllustrisTNG.

---

## Features

- **Fourier decomposition** of stellar surface density: modes m = 1–4,
  Rix & Zaritsky (1995) normalisation, radial amplitude/phase profiles.
- **Phase-coherent bar length** (Aguerri et al. 2009) suppresses
  shot-noise false positives.
- **Iterative shrinking-sphere centring** (Power et al. 2003).
- **GADGET-2 √a velocity conversion** (Springel 2005; Nelson et al. 2019)
  required for internally consistent kinematics on IllustrisTNG snapshots.
- **Bootstrap uncertainties** (N_boot = 200).
- **Validated** against synthetic galaxies to <2% at N = 5 × 10⁵.
- **Runtime**: 5.76 hours for 923 downloaded subhalos (915 disc-quality
  survivors) on a single machine.

## Installation

### Option 1: pip

```bash
git clone https://github.com/Abbos998/TNGGalaxyLab.git
cd TNGGalaxyLab
python -m venv venv
source venv/bin/activate      # or venv\Scripts\activate on Windows
pip install -r requirements.txt
```

### Option 2: conda

```bash
git clone https://github.com/Abbos998/TNGGalaxyLab.git
cd TNGGalaxyLab
conda env create -f environment.yml
conda activate tnggalaxylab
```

### Option 3: Docker

```bash
docker build -t tnggalaxylab .
docker run -it --rm -v $(pwd):/workspace tnggalaxylab bash
```

## Quickstart

**Reproduce every headline statistic** (uses the released catalogue,
runs in seconds):

```bash
python scripts/reproducibility_audit.py
```

**Validate against synthetic galaxies** (~5 minutes):

```bash
python scripts/validate_synthetic.py --output validation/ \
    --n-values 1000 5000 20000 100000 500000 --replicas 5
```

**Analyse a single TNG50 subhalo**:

```bash
python scripts/analyze_tng50_subhalo.py \
    --cutout batch_tng50/batch_output/cutouts/cutout_558067.hdf5 \
    --output results_558067.json
```

**Run the full 915-galaxy batch pipeline** (requires TNG API token;
copy `batch_tng50/batch_config.example.yaml` to
`batch_tng50/batch_config.yaml` and fill in your token):

```bash
cd batch_tng50
python 01_select_subhalos.py   # queries API, writes subhalo_ids.txt
python 02_download_cutouts.py  # ~3 hours, 13 GB
python 03_process_batch.py     # ~1.5 hours
python 04_build_catalog.py     # <5 min, writes catalog.csv/.fits
```

## Reproducibility

The full 915-galaxy TNG50-1 catalogue is available at:

- **GitHub**: this repository (`batch_tng50/batch_output/catalog.csv`)
- **Zenodo**: [10.5281/zenodo.21363952](https://doi.org/10.5281/zenodo.21363952)

All figures in the paper can be regenerated by:

```bash
python scripts/validate_synthetic.py --output validation/  # Figures 1–3
python batch_tng50/make_paper_figures.py                   # Figures 4–13
```

An independent audit of all headline statistics against the released
catalogue --- using only the Python standard library and no part of
the TNGGalaxyLab pipeline --- is provided in
`scripts/reproducibility_audit.py` and appears as Appendix C of the
manuscript.

## Pipeline parameters (as used in the manuscript)

The batch configuration file `batch_tng50/batch_config.example.yaml`
records the exact parameters used to produce the 915-galaxy catalogue:

| Parameter | Value | Manuscript reference |
| --- | --- | --- |
| Simulation, snapshot | TNG50-1, snapshot 99 (z = 0) | §4.1 |
| Stellar-mass window | 3.16×10⁹ < M★/M☉ < 10¹¹ | §4.1 |
| Fourier modes | m = 1–4 | §2.1 |
| Radial grid outer edge | r_out = 15 kpc | §2.4 |
| Radial bins | n_bins = 40 (width 0.375 kpc) | §2.4 |
| R&Z95 aperture | [1.5, 2.5] × R_d | §2.2 |
| Bar detection threshold | A₂ > 0.2 | §2.4 |
| Phase-coherence tolerance | Δφ_tol = π/8 (22.5°) | §2.4 |
| Bootstrap resamples | N_boot = 200 | §2.5 |

## Runtime performance

Measured on a single Windows/Anaconda workstation
(Intel-class CPU, no GPU, single-core Python):

| Stage | Time | Notes |
| --- | --- | --- |
| Query TNG API | ~1 min | 923 subhalos |
| Download 923 HDF5 cutouts | ~3 hours | 13 GB total |
| Fourier processing | ~1.5 hours | 22.5 s / galaxy |
| Catalog build | <30 s | CSV + FITS |
| **Total (923 galaxies)** | **5.76 hours** | resumable |

The pipeline is embarrassingly parallel and can be trivially
distributed across cores or nodes for larger simulations.
